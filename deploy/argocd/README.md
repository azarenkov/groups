# GitOps values

`modules/rift` with `delivery = "argocd"` creates an Argo CD `Application` that renders `deploy/helm/rift` with two value sources:

1. `envs/<environment>/values.yaml` from this directory — the part that changes on every release. `release-services.yml` writes the freshly built tag here after the images are pushed, so a git tag `vX.Y.Z` ends up as `image.tag: X.Y.Z` in `envs/staging/values.yaml` and Argo CD rolls it out.
2. `valuesObject` generated by Terraform — hosts, datastore endpoints, secret names and everything else that belongs to the cluster rather than to the release. It never carries `image.*`, so the tag in the environment file is what gets deployed.

Secrets never go through git: Terraform writes them into the namespace and the chart references them through `existingSecret`.
