## How feedback is recorded

1. After each meeting or review, add a row to the session table with the date, the deliverables reviewed and a link to the meeting notes, if any.
2. Add one row per comment to the decisions table, with the decision (**accepted**, **partly accepted**, **declined with reason**) and a link to the commit or pull request that addressed it.
3. Comments given directly on GitHub pull requests are linked by URL in the "Addressed in" column.
